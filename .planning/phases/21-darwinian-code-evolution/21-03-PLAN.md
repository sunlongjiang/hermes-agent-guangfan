    ```python
    import hashlib
    import os
    import random
    import subprocess
    from dataclasses import dataclass, field
    from pathlib import Path
    from typing import Optional
    
    # D-08 递归自进化防御路径黑名单

    ```
    
    **2. CodeTarget dataclass**
    字段：component_path: Path, test_file_path: Path, baseline_size_bytes: int, original_source: str, schema_version: str = "1.0", hermes_agent_commit: str = ""
    含 `to_dict()` 方法（JSON 序列化用，Path → str）
    
    **3. find_target(component: str, hermes_repo: Path) -> CodeTarget**
    - 首先检查 component 是否命中 _FORBIDDEN_PATH_PREFIXES 任一前缀 → raise ValueError("Refusing to evolve evolution/ itself" 或 "Refusing to evolve security-sensitive path")
    - 解析 component_path = hermes_repo / component；不存在则 raise FileNotFoundError
    - 推断 test_file_path：components/tools/ansi_strip.py → tests/tools/test_ansi_strip.py（替换 component 路径中的 tools/ → tests/tools/test_）
    - 获取 hermes_agent_commit：`subprocess.run(["git","rev-parse","--short","HEAD"], cwd=hermes_repo, capture_output=True, text=True)` 失败时用 "" 
    - 返回 CodeTarget(component_path, test_file_path, baseline_size_bytes=component_path.stat().st_size, original_source=component_path.read_text(), hermes_agent_commit=commit)
    
    **4. find_target_tests(target: CodeTarget) -> list[dict]**
    - 读取 target.test_file_path 内容，ast.parse()
    - walk ast.FunctionDef + ast.AsyncFunctionDef，收集名字以 "test_" 开头的函数
    - 对于 @pytest.mark.parametrize 装饰器，提取第一个参数（param_names str）和第二个参数（values list） → parametrize_count = len(values)；无装饰器则 parametrize_count = 1
    - 按函数名关键词自动桶化：含 "csi"/"cursor"/"move"/"arrow" → "csi"；含 "sgr"/"color"/"bold"/"blink"/"dim"/"reverse"/"underline" → "sgr"；含 "osc"/"title"/"hyperlink" → "osc"；其余 → "other"
    - 返回 list[dict]：每个 dict 含 test_id（函数名）、bucket（str）、parametrize_count（int）
    - 在 manifest dict 中加入 schema_version = "1.0"，hermes_agent_commit 取自 target
    - 返回格式：直接返回 list[dict]，不含 wrapper；调用方自己处理 schema_version
    
    **5. stratify_tests(manifest: list[dict], seed: int = 42) -> dict**
    - 按 bucket 分组，每组内 random.seed(seed) 后 shuffle
    - holdout: 从每桶取 HOLDOUT_PER_BUCKET[bucket] 个；剩余全部作 train
    - 若某桶不足 HOLDOUT_PER_BUCKET 个，round-robin 补齐（取其他桶最小 bucket 的一个来凑）
    - 返回 {"train_ids": [...test_id...], "holdout_ids": [...test_id...]}
